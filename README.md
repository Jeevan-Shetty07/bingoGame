# ⚡ BINGO_CORE: High-Frequency Win System

Welcome to the ultimate Bingo cockpit. This isnt your grandmas bingo—this is a high-octane, Cyber-Glass experience built for speed and visual dominance.

## 🚀 Featurs
- **Interactive 3D Background**: Powered by Vanta.js for that sweet digital mesh vibe.
- **Cinematic Transitions**: GSAP staggers that make the UI feel buttery smooth.
- **Real-time Synchronization**: Socket.io keeps everyone in the loop without lagg.
- **Holographic Winner Screen**: A total overhaul of the victory page with rotating rings and glitchy text.
- **Mobile Optimized**: Play on your phone or your laptop, it looks great everywhere.

## 🛠️ Setup
1. Clone the repo (you probly already did this).
2. Run `npm install` to get all the stuff.
3. Run `npm start` to fire up the server.
4. Open `localhost:3000` and start wining.

## 🕹️ How to Play
- Create a room or join a network link.
- Tap the numbers as they're called.
- Hit the **BINGO!** button when you got a line.
- Flex your win on the chat.
